## 六、常见问题

### Q1: 页面加载慢？
**A**: 首次加载可能需要几秒（81 篇文章数据约 500KB）。建议：
- 使用 Chrome/Edge/Firefox 最新版
- 关闭浏览器缓存清理工具
- 如仍慢，可联系优化

### Q2: 搜索不到文章？
**A**: 检查：
- 关键词是否拼写正确
- 尝试更短的关键词
- 检查标签（如"W7"而非"第 7 周"）

### Q3: 文章显示不全？
**A**: 刷新页面（F5 / Ctrl+R / Cmd+R）

### Q4: 如何离线使用？
**A**: 站点本身就是离线的！双击 index.html 即可，无需联网。

### Q5: 如何在手机上看？
**A**: 
1. 将站点文件夹压缩为 zip
2. 传到手机并解压
3. 用浏览器打开 index.html
4. 或启动本地服务器后用手机访问（需同一 WiFi）

## 七、技术架构

### 7.1 纯静态架构

```
index.html      ← 入口壳
style.css       ← v3 品牌色系
app.js          ← 核心逻辑
data.js         ← 索引调度器
data-*.js       ← 6 个数据文件（81 篇文章）
assets/         ← 3 份 xlsx 工具
```

**特点**：
- 零依赖：无需后端、无需数据库
- 双击即用：无需安装、无需配置
- 离线可用：所有数据本地化
- 秒级启动：无网络请求

### 7.2 数据架构

**多文件架构**（v3 核心）：
- data.js: 索引调度器（17 行）
- data-theory.js: 理论课堂（35 篇，211.7 KB）
- data-tools.js: 实操工具箱（21 篇，116.6 KB）
- data-path.js: 学习路径（1 篇 + 13 周，15.5 KB）
- data-lab.js: 沙盘训练（5 篇，38.5 KB）
- data-cases.js: 案例库（17 篇，72.0 KB）
- data-law.js: 法规参考（2 篇，17.3 KB）

**优势**：
- 按栏目拆分，维护方便
- 单文件不超过 250 KB，加载快
- 新增文章只需编辑对应数据文件

### 7.3 元数据规范

**13 字段标准**：
```javascript
{
  id: "theory-book01-01",           // 唯一标识
  title: "文章标题",                 // 文章标题
  tags: ["入门", "W1", "危机处置"],  // 标签（难度/周次/主题）
  difficulty: "入门",               // 难度（入门/进阶/高阶）
  week: "W1",                       // 对应周次
  source: "来源说明",               // 素材来源
  updated: "2026-09-17",            // 更新日期
  section: "theory",                // 所属栏目
  subsection: "crisis",             // 所属子板块
  summary: "摘要文本",              // 150 字摘要
  relatedIds: ["theory-book01-02"], // 相关文章 ID
  contentHtml: "<p>HTML 内容</p>",  // 文章正文
  downloadUrl: ""                   // 下载链接（如有）
}
```

## 八、内容补充流程

### 8.1 新增读书报告

1. 准备 docx 文件（放在 `01_认知理论/` 目录）
2. 用 Python 脚本拆分为 5 篇：
   ```python
   python gen_theory.py
   ```
3. 脚本自动生成 data-theory.js 追加代码
4. 复制到 data-theory.js 的 articles 对象
5. 刷新浏览器验证

### 8.2 新增案例

1. 准备 markdown 文件（放在 `content/` 目录）
2. 文件头部添加 YAML frontmatter：
   ```yaml
   ---
   id: case-18
   title: 案例库 18：新案例标题
   tags: [案例库, 主题1, 主题2]
   difficulty: 进阶
   week: W10
   source: 来源说明
   updated: 2026-09-17
   ---
   ```
3. 用 Python 脚本生成 JS 代码：
   ```python
   python p1_batch_remaining.py
   ```
4. 复制到 data-cases.js 的 articles 对象
5. 刷新浏览器验证

### 8.3 新增工具/模板

流程同 8.2，生成后追加到 data-tools.js
