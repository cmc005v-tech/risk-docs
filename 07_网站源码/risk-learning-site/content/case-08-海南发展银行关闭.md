## 摘要

海南发展银行 1998 年被关闭，成为国内首例银行倒闭事件，但清算工作至今仍未结束，被称为"清算悬案"。本案例是"金融风险处置不能拖延"最极端的实践注脚：企业风险处置同样存在"拖到不可收拾才动手"的失败模式，处置平台（谁来做、用什么流程做）选择不当，会让损失在争议中持续发酵数十年。**案例关键词：关闭清算、拖延、处置平台、损失固化。**

## 核心案情

| 要素 | 详情 |
| --- | --- |
| 背景 | 上世纪 90 年代海南房地产泡沫破裂，信用社乱象与储蓄流失问题恶化 |
| 关闭 | 1998 年央行宣布关闭海发行，由工商银行托管其债权债务 |
| 后续 | 清算工作长期拖延，储户与债权人的清偿长期悬而未决 |
| 教训 | 处置动作拖延 + 处置平台缺位，是危机恶化的"慢性加速器" |

**风险模式链**：风险累积 → 危机爆发 → 关闭/止损动作迟缓 → 清算平台与流程缺失 → 损失长期冻结、社会成本持续扩大。

## 处置经过（对照分析）

- **拖延的现实原因**：损失承担主体不清（谁出钱）、资产处置复杂、各方博弈拖延——本质上是在"不敢拍板"中错失处置窗口；
- **对照教训**：处置时机（何时动手）与处置平台（由谁、按什么流程动手）必须同时确定，缺一个都会形成"僵局型拖延"；
- **企业映射**：项目烂尾、坏账长期挂账、亏损业务线"再等等看"，都是海发行式拖延的微观版本。

## 复盘要点

1. **"不得不救"时才动手=被动挨打**：成功的处置在危机全面爆发前已启动预案；失败的处置总在"最后一刻"仓促决策；
2. **处置平台要事前选定**：是私下和解、行业协会调解、仲裁还是诉讼？不同平台的速度、成本、执行力差异巨大，但犹豫不选本身就是最大的成本；
3. **损失分担要主动设计**：拖延的原因往往是"没人愿意认损"——企业应预先定义坏账计提规则、亏损止损线，让"认损"成为制度动作而非个人决策。

## 适用迁移

- 建立"风险事件处置时限表"：发现风险后 N 天内完成评估、N 天内启动止损、N 天内选定处置平台，用时限对抗拖延；
- 坏账与亏损的"自动认损机制"：达到阈值自动触发计提与止损流程，无需等管理层拍板;
- 把"处置平台清单"提前备好：常见纠纷类型的调解/仲裁/诉讼路径与成本对比，事前沉淀。
