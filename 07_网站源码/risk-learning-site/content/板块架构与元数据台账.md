## 三、写作规范（结构模板）

- **岗位认知类**（career-*）：摘要 → 核心框架 → 章节拆解 → 应用要点（职业认知适配）
- **方法论卡类**（method-*）：摘要 → 适用场景 → 分步拆解（含步骤/关键动作/交付物）→ 避坑要点

- **工具箱类**（tool-*）：摘要 → 模板/工具定位 → 字段与操作拆解 → 应用场景与避坑
- **案例库类**（case-*）：摘要 → 核心案情 → 处置经过 → 复盘要点 → 适用迁移

- **法规参考类**（law-*）：摘要 → 规范定位 → 条款拆解（按层级组织）→ 使用建议/速查索引
