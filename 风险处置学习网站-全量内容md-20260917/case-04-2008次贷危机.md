## 摘要

2008 年全球金融危机的核心教训是"风险传导的放大效应"：单一资产类别（次级房贷）的违约，通过资产证券化链条传导为全球性系统性风险；而应对层面，本书以美国迅速推出量化宽松为例，展示了"逆周期操作"的正面价值。本案例聚焦传导机制与果断处置，适配到企业的"单一风险点传导放大"场景。**案例关键词：次贷违约、证券化传导、逆周期操作、系统性风险。**

## 核心案情

| 阶段 | 事件 |
| --- | --- |
| 病灶 | 次级房贷违约率上升，抵押债权被打包成证券化产品分散到全球投资者 |
| 传导 | 单一产品违约 → 持有机构巨亏 → 同业拆借冻结 → 雷曼倒闭 → 全球流动性危机 |
| 应对 | 美联储迅速推出量化宽松等逆周期政策，稳定金融体系关键功能 |
| 对照 | 相比大萧条时期的拖延，2008 年的果断操作压缩了衰退持续时长 |

**风险模式链**：单一风险点违约 → 通过"共担结构"扩散 → 市场信任崩塌 → 连锁挤兑。企业层面的映射：单一客户逾期 → 传导到本企业支付能力 → 供应商断供 → 项目停滞 → 客户流失，层层放大。

## 处置经过（对照分析）

- **传导路径识别**：处置成功的先决条件是看清风险"从哪里来、往哪里去"——次贷危机中，只有识别出证券化传导链（原始放贷 → 打包 → 分销 → 持有），才能判断哪些机构是"关键救助者"；
- **果断的逆周期动作**：危机时期快速放弃"收缩自保"的本能，选择注入流动性、保住信贷循环——对照企业：危机时优先保住"核心现金流通道"，而不是全面砍成本导致核心功能瘫痪。

## 复盘要点

1. **识别传导链优先于处置单点**：先画"风险影响路径图"（初始点 → 中间环节 → 最终后果），再决定把资源投向哪个环节；
2. **关键救助者的选择**：企业内部谁是最终决策者、外部谁能提供资源（法务/财务/合作方/政府纾困）——救助者的及时性与资源质量决定成败；
3. **逆周期操作的本质**：非常态时期的目标排序是"止住损失蔓延 > 保住核心功能 > 确保生存底线"，利润和规模让位。

## 适用迁移

- 对"集中度风险"设阈值：单一客户应收占比超过 30%、单一币种敞口过高、单一供应商依赖过重，均应触发预警；
- 提前储备"逆周期资源包"：备用授信、可快速变现资产、已签约的应急合作方——确保危机时能第一时间注入"流动性"。
