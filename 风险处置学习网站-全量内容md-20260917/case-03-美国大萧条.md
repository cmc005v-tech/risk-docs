## 摘要

1929-1933 年美国大萧条是近代经济史上最典型的"拖延型危机"：股市崩盘后，政策层在流动性收紧、银行连环倒闭面前迟迟未扩张货币供应，任由信贷循环中断，最终演变为历时四年的全球性大衰退。本案例拆解"大萧条前的模式"与"处置迟缓的代价"，将其适配为企业的风险预判与管理决策反例。**案例关键词：信贷过度扩张、杠杆堆积、流动性突然收紧、拖延成本。**

## 核心案情

| 阶段 | 事件 |
| --- | --- |
| 膨胀期 | 信贷过度扩张 → 资产价格泡沫 → 杠杆堆积，投机需求掩盖真实购买力 |
| 崩盘期 | 1929 年股市崩盘后流动性突然收紧，银行大量倒闭、存款挤兑 |
| 恶化期 | 政策未及时扩张货币供应（逆周期操作缺失），连锁违约扩散至实体企业 |
| 后果 | 1929-1933 年经济深度衰退，失业率飙升至 25% 上下 |

**风险模式链**：信贷过度扩张 → 资产价格泡沫 → 杠杆堆积 → 流动性突然收紧 → 连锁违约。这条链条在企业层面同样成立：过度融资扩张 → 资产估值虚高 → 短债长投 → 融资环境突变 → 连环爆雷。

## 处置经过（对照分析）

- **拖延式路径（真实发生）**：危机爆发后未第一时间注入流动性、未及时隔离系统性风险，结果单一银行倒闭演变为全体系挤兑，处置成本指数级上升；
- **对照的果断式路径（事后总结）**：若在危机初期即实施"逆周期操作"（扩张货币、稳定预期、隔离坏账），可以显著压缩衰退深度与时长。

## 复盘要点

1. **预判不是算命**：大萧条前的模式全部可识别——信贷扩张速度、杠杆率、流动性与资产价格的背离，都是"如果A则B"的条件反射素材；
2. **处置时机决定成败**：风险发现后的前 30 天是黄金窗口；拖延 1 个月与拖延 3 个月的处置成本差异远超线性；
3. **逆周期思维**：企业危机时期不能用常规经营逻辑（扩张、追利润）应对，而要切换到"保住核心功能、止住损失、确保生存"的非常态逻辑。

## 适用迁移

- 企业中"过度融资扩张 → 资产泡沫 → 流动性收紧"的预警：关注负债率、短债占比、资产价格与现金流的背离；
- 处置预案中必须预设"流动性突然收紧"场景：保持现金冗余 + 备用授信额度 + 可快速变现资产清单。
