## 摘要

某物流企业与资信不良的承运商合作，导致货物被扣押——跨境物流链条中"合作方资信"是最常见也最致命的风险点。本案例运用稳评的"利益相关者分析"思想：签约前不仅审查承运商自身的证照与报价，更要走访其存量客户、核查实际控制人资信、评估其争议处理能力，从源头阻断"货物到手就会被扣"的合作。**案例关键词：合作方资信、承运商尽调、利益相关者、货物扣押。**

## 核心案情

| 要素 | 详情 |
| --- | --- |
| 事件 | 某物流企业与资信不良的承运商合作，货物被对方扣押 |
| 病根 | 签约前尽调不充分：只看报价与证照，未核查实际控制人资信与履约记录 |
| 放大点 | 货物在对方手上，谈判地位完全被动；扣货引发客户索赔与信用受损 |
| 后果 | 已投入资金沉没 + 客户信任受损 + 被迫接受不利条件赎货 |

**风险模式链**：尽调不充分 → 与资信不良合作方签约 → 货物交付对方控制 → 扣货/违约 → 被动谈判。

## 处置经过（对照分析）

- **失败路径（真实风险）**：低价诱惑 + 快速签约 + 未做背景核查 → 合作方挪用或扣押货物 → 处置被动；
- **正确路径（对照）**：签约前把承运商当作"利益相关者"全面评估——① 走访其其他客户了解履约记录与争议处理能力；② 核查实际控制人征信、涉诉、失信被执行记录；③ 抽查其仓库/运力真实性与货权凭证管理能力；④ 合同约定扣货禁止条款与违约金。

## 复盘要点

1. **"便宜"是风险信号而非决策依据**：价格显著低于市场均价的承运商，往往以其他方式"找补"——扣货、压价、转包；
2. **尽调要穿透到"实际控制人"**：公司主体干净不等于实际控制人干净，征信与涉诉必须核查到自然人层面；
3. **利益相关者沟通前置**：稳评"公众参与"思想转化到商业场景，就是"走访合作方的其他客户、终端客户"，用第三方视角验证合作方口碑；
4. **货权控制权是最硬的安全垫**：能自己掌控货权凭证（提单/运单/仓单）就不要交付控制权，这是扣货风险的终极防线。

## 适用迁移

- 承运商/合作方准入尽调：证照 + 实控人征信 + 涉诉查询 + 现有客户走访 + 仓库/运力实地核验；
- 合同条款：扣货禁止条款、违约金、货权凭证归属、争议期间货物处置规则；
- 动态监控：合作后定期复评，出现拖欠运费、频繁转包、关键人员离职等信号立即预警。
