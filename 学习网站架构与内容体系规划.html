Learning Site Blueprint

学习网站架构与内容体系规划
风险处置实战系列学习站

参照「跨境电商高级实战系列」学习网站的体系化课程模式，将工作区 18 份风险处置内容资产，重构为一个「看得懂理论、拿得到工具、练得出技能」的实战型学习站。本规划为蓝图文档，网站原型在规划确认后实施。

规划基准：2026-09-14| 内容映射：18 源文件 → 6 大栏目| 学习主线索：3 个月 / 13 周成才路径| 技术形态：纯静态 · data 驱动 · 双击即用

1站点定位与参照模式

回答两个问题：向谁提供什么价值、参照什么样的成熟形态。

目标人群与价值主张

人群痛点本站价值
转型入行者（主）想学企业风险处置，但资料零散、不知从何下手、无业界标准3 个月成才路径 + 全量方法论 + 可直接套用的模板工具
在岗财务/法务/管理者风控知识碎片化，缺体系；学了无法立刻用于业务「理论→模板→工具→沙盘」闭环，学了就能产出报告/方案
跨境物流/电商从业者（特色）行业特有风险（跨境纠纷、政策突变、舆情）缺乏适配方法5 篇读书报告均含跨境物流/企业适配章节，站内独立成块

参照模式：跨境电商高级实战系列

  • 体系化课程结构：按「系列 → 模块 → 课时」三层组织，本站对应「实战系列 → 六大栏目 → 文章/任务」
  • 学练用一体：每模块配可下载工具与练习任务，不只给内容，还给交付物
  • 实战导向文案：栏目名用行动语言（理论课堂 / 实操工具箱 / 沙盘训练），弱化"读书笔记"感
  • 技术延续已验证经验：沿用本工作区已有的纯静态学习站架构（index.html + app.js + data.js + style.css），并承接 Astrology Academy 项目「JSON 数据驱动 + 双击即用」的成熟模式 — 本站 data.js 用 JS 变量替代 fetch JSON，比 JSON 方案更稳：file:// 直接打开无 CORS 限制

设计原则：「路径」是骨架（告诉学习者怎么走），「理论」是血肉（方法论全文），「工具」是双手（直接拿去做事），「沙盘/案例」是考场（验证学到什么）。六个栏目恰好覆盖学习全链路。

7技术方案

延续已验证的纯静态路线：零依赖、零部署成本、双击即用，同时规避此前项目踩过的坑。

risk-learning-site/ ← 网站源码区（内容与源码分离） ├─ index.html 入口壳：侧栏 + 主内容 + 脚本挂载 ├─ style.css 样式：品牌变量 + 组件 + 移动端 + 打印 ├─ app.js 逻辑：导航/路由/搜索/进度/沙盘交互 ├─ data.js 数据层（核心）：SITE_DATA.sections + articles │ ├─ site: 标题/副标题/版本/最近更新 │ ├─ sections: 6 栏目 × 子板块 × 文章引用 │ └─ articles: 每篇 {id,title,tags,difficulty,week,content} └─ assets/ （可选）模板/工具下载文件引用目录

实现要点与避坑清单

  • 数据格式：data.js 用 JS 对象（非 fetch JSON），file:// 双击直接可用，天然规避 CORS — 这是相对 Astrology Academy JSON 方案的关键改进，务必保持
  • 字符串卫生：JS 字符串内禁裸双引号，中文语境用「」替代，杜绝引号逃逸问题
  • 文章元数据：每篇带 difficulty（入门/进阶/高阶）、week（对应学习周）、tags，供路径页与筛选联动
  • 缓存规避：data.js 结构升级后，通过版本文件或改文件名强制刷新（浏览器 JS 缓存顽固，必要时提示无痕模式）
  • 长文渲染：读书报告正文量约 8-10 万字总量级，按章节拆分存储（不存超大单条），正文用 contentHtml 字段直接存 HTML，绕开简易 Markdown 渲染器的已知缺陷
  • 本地校验：开发期以 python -m http.server 8765 起本地服务便于调试，交付形态仍为双击可用
  • 合规：白皮书版权归融智研究院，站内标注出处；读书报告为个人学习笔记性质，站内声明"个人学习整理"
